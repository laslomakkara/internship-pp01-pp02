## Воспроизведение

Установите Python 3 и зависимости командой `python -m pip install jupyter pandas numpy pillow`. Поместите выданные CSV в локальную папку `data/` рядом с ноутбуком, откройте его в Jupyter и запустите все ячейки. Сохранённые результаты содержат агрегаты. Исходные CSV исключены из Git.

```text
data/
  ab_test_users_groups.csv
  ab_test_events.csv
```

Для запуска из терминала выполните `python ab_test_gamification.py`. Скрипт печатает таблицы и сохраняет два PNG в `data/analysis_charts/`. Параметры `--data-dir` и `--charts-dir` позволяют указать другие папки.
